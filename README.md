# Cognifyz Technologies – Machine Learning Internship

This repository contains my Machine Learning internship projects completed as part of the Cognifyz Technologies internship program.

## 📌 Projects

### Task 1 – Predict Restaurant Ratings
Built machine learning regression models to predict restaurant ratings.

**Models Used:**
- Linear Regression
- Decision Tree Regressor

**Best Model Result:**
- R² Score: 0.5697
- RMSE: 0.3648

---

### Task 2 – Restaurant Recommendation
Built a content-based restaurant recommendation system based on:

- Cuisine preference
- Price range
- Cosine similarity

**Results:**
- Cuisine Match Rate: 93.33%
- Price Match Rate: 100%
- Average Similarity: 0.8916

---

### Task 3 – Cuisine Classification
Built a Random Forest classification model to classify restaurants into cuisine categories.

**Results:**
- Accuracy: 40.98%
- Weighted Precision: 0.3617
- Weighted Recall: 0.4098

The analysis also examined performance across different cuisines and identified challenges such as class imbalance.
